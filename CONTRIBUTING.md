# Contributing to RROM

Thank you for your interest in the Ravenhelm Release Operations Methodology (RROM).

## Editorial & Documentation Contributions

We welcome contributions that improve clarity, fix typographical errors, improve code samples, or expand real-world deployment patterns.

1. **Fork & Branch**: Create a branch off `main` for your changes.
2. **Conventions**: Maintain the voice, structure, and formatting standards defined in the existing chapters.
3. **Pull Request**: Open a pull request against `main` describing the rationale for the change.

## Doctrinal Contributions

Changes to the core doctrine, axioms, or the numbered principles (`RP-1` through `RP-18`) represent load-bearing governance shifts and require maintainer review and approval.
